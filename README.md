# floatype/homebrew-tap

[Floatype](https://github.com/floatype/floatype) を Homebrew で入れるための tap です。

```sh
brew install --cask floatype/tap/floatype
```

入れたあとの手順（ログアウトと入力ソースの追加）は、インストールの最後に表示されます。

- 更新: `brew upgrade`
- 消し方: `brew uninstall floatype`（設定と学習は残ります）

cask は、floatype の新しいリリースが公開されると 6 時間ごとのワークフローで更新されます。
